Smart Monitoring System (November 2025 ~ Present)

Sponsor: Korean Government R&D Project

Affiliated Institution: SECERN AI

This is an R&D project to build an AI-based monitoring system that monitors situations occurring at airports and public places, detects people and vehicles, recognizes their attributes, and provides real-time information to the control center. The system integrates multiple AI models for detection, recognition, and re-identification tasks to enhance public safety and security.

Tech Stack: Python, PyTorch, H100/A100 GPU, TensorRT

My Responsibilities

  • Data preprocessing pipeline and labeling system development
  • Detection/Recognition model development
  • VLM-based pseudo labeling and attribute recognition model development
  • Model optimization (TensorRT) and system integration

1. Vehicle/Person Detection (+11~13% Improvement)

Challenge: Low detection rate in service environment due to domain gap between training data and real-world deployment scenarios.

Solution: Implemented an iterative improvement pipeline - collected undetected images from the service environment, labeled them, and performed additional training to improve model performance.

Results:

  • Vehicle Detection: 95.8% accuracy
  • Person Detection: 95.2% accuracy
  • License Plate Detection: 94.5% accuracy

2. Person Re-Identification (+12% Improvement)

Challenge: Insufficient labeled data and severe class imbalance in the person re-identification dataset.

Solution: Applied HDBSCAN unsupervised clustering algorithm to generate pseudo labels from unlabeled data, and implemented Temperature-based Sampler to address class imbalance during training.

Result: Achieved 88.7% accuracy for Person Re-ID.

3. Vehicle Brand/Color Recognition (New Development)

Challenge: No existing dataset available for Korean vehicle brands. Joint training of brand and color recognition caused performance degradation.

Solution: Collected and curated custom dataset for Korean vehicles. Utilized Vision Language Model (VLM) for automated pseudo labeling. Implemented separate training pipelines for brand and color recognition to prevent interference.

Results:

  • Vehicle Brand Recognition: 87.4% accuracy
  • Vehicle Color Recognition: 85.2% accuracy

4. License Plate Recognition

Developed an OCR pipeline for Korean license plate recognition, consisting of text detection and text recognition modules.

Result: Achieved 93.1% accuracy for License Plate Recognition.

5. VLM-based Attribute Recognition (In Development)

Currently developing a Vision Language Model (VLM) based approach for person attribute recognition. The model recognizes detailed attributes including upper body clothing, lower body clothing, shoes, accessories, and more.

Status: In development

6. Abnormal Behavior Detection (In Development)

Developing a two-stage abnormal behavior detection system that combines rule-based algorithms for initial detection with VLM-based verification for double-checking to reduce false positives.

Status: In development (1st Algorithm + 2nd VLM Double-Check)

7. Pipeline Efficiency Improvements

Labeling Productivity: Improved by 40% through implementation of automated labeling tools and VLM-based pseudo labeling.

Preprocessing Time: Reduced by 15% through optimized data preprocessing pipeline.

Model Optimization: Achieved 7% speed improvement through TensorRT optimization while maintaining real-time performance (30+ FPS).
