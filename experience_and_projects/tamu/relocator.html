Robotic Arm Object Relocator (September 2022 ~ December 2022)

Texas A&M University | Graduate Course Project

Tech Stack: C/C++, Arduino, Matlab/Simulink, SolidWorks, 3D printing

My Role: inverse-kinematics and control-algorithm design, sensor integration and automation, and Arduino embedded integration.

Automated machinery is widely used in the manufacturing industry to simplify the amount of labor needed and improve precision. Examples include packaging items, putting caps on bottles, and assembling cars. A robot arm that can move an item from one location to another was designed to contribute to the area of automation, more specifically, for items needing to be moved from one conveyor belt to another.

The robot arm moves any item to a pre-specified location by calculating the distance to the item and using a digital feedback controller to minimize tracking errors and provide smooth controls.

System Design & Workflow

A radar sensor checks for an object within the robot workspace and finds the angle to get within a pre-specified distance to the object using proportional control. Once the robot has reached the object, it transports it to another location and starts the process again.

Robot Arm Design

Five servos control the movement of the robot while a sixth servo controls the claw mechanism. An ultrasonic sensor is mounted at the end effector for detecting objects and use in the feedback control.

An important component of the final design is the base configuration. A servo could not be directly mounted to the base due to its shaft diameter and the fact that all the weight from the system would resolve onto the shaft, so a bearing was added at the base to resolve this issue.


Hardware Components

  • Microcontroller: Arduino Mega
  • Motor Shield: Adafruit 16-Channel 12-bit PWM/Servo Shield (I2C interface)
  • Actuators: 6x High Torque Servos (5 for arm movement, 1 for claw)
  • Sensor: Ultrasonic sensor mounted at end effector
  • Mechanical: 3D printed components, bearing (r24-2rs 1-1/2"x 2-5/8"x 9/16"), mechanical gripper

Feedback Control

To ensure the system could find the angle needed to reach the object with zero steady-state error, a proportional controller was implemented. The ultrasonic sensor on the end effector was used to find the desired arm angle to keep the object within 2 inches.

The distance to the object is calculated using:

dobj = larm + lend_arm + dsensor    where    larm = L sin(θ)

A discretized proportional controller was used:

u[k] = u[k-1] + kpe[k] - kpe[k-1]    where    e[k] = dref - dact

The gain kp = 2 was chosen through trial and error to minimize oscillation.

Experimental Results

Initial testing showed the servomotor angles were nonlinear, and a correction term was added within the code to account for this. Each of the servomotors controlling the arm was tuned to smooth the control since the motion was harsh initially.

Proportional Gain (kp) Comparison

kp Value Observation
0.5 High oscillation around reference point
1.0 Moderate oscillation
2.0 Optimal - No oscillation around setpoint

After preliminary tuning and testing, the robot arm successfully grabbed the object, moved it to a pre-defined location, and returned home.

Discussion & Future Work

Once the final design was assembled, several potential improvements were identified:

  • Servo Synchronization: Synchronizing each pair of servomotors proved difficult. Fewer servomotors can achieve the same goal (only one servomotor on the main arm and end effector), which would also reduce overall cost.
  • Workspace Limitation: The robot arm workspace was limited due to the weight of the claw mechanism. A lighter claw would result in further extension of the robot arm.
  • Enhanced Control: The servomotors chosen contained internal speed control for high precision tracking, which limited feedback control options. Using servomotors with position feedback would enable robotic manipulator calculations, adaptive control, and feedforward control.

Conclusion

The proportional controller successfully calculated the necessary angle for the claw to get within 2 inches of the object. Oscillations from proportional gain were eliminated through trial and error. Smoothing of the robot arms was tuned using time delays to eliminate harsh movements. Overall, the robot arm design and controller successfully detected an object and transported it to another location with little error, satisfying the system requirements.
