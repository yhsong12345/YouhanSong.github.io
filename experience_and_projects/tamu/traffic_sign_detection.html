Project Overview

Texas A&M University | Master's Thesis (June 2023) | Advisor: Dr. Reza Langari

This Master's thesis served as the perception module of the AVA (Autonomous Vehicle for All) project. It developed an enhanced YOLOv7-based real-time traffic sign and signal detection system optimized for high-speed driving scenarios (75+ mph) and challenging environmental conditions. The research addresses critical challenges in autonomous vehicle perception systems where accurate detection of distant and small traffic elements is essential for safety-critical decision making.

The main objective was to propose an improved YOLOv7 model that achieves better performance than the original while trained with random-quality and limited datasets. Unlike existing models trained on MS COCO that lack traffic sign/light detection capabilities, this work specifically targets real-world autonomous driving requirements where the perception system must reliably detect and classify traffic elements for proper longitudinal/lateral control decisions.

Key Achievement

Achieved +1.1% improvement in mAP@0.5 (92.3% → 93.4%) over the original YOLOv7 model through strategic modification of the activation function from SiLU to ELU, significantly enhancing detection accuracy for distant objects and resolving multi-class confusion scenarios.

Research Motivation

  • Existing CV models (YOLO series) trained on MS COCO lack traffic sign/light detection
  • High-speed driving causes camera resolution degradation and motion blur
  • Similar features between traffic signs lead to misclassification
  • Limited high-quality datasets available for traffic sign detection

Research Contributions

  • Modified YOLOv7 architecture with ELU activation for improved gradient flow
  • Constructed comprehensive dataset of 29,978 annotated images (14 classes)
  • Implemented ROS-based real-time testing pipeline for validation
  • Demonstrated superior performance in distant object detection scenarios

Dataset Statistics

Constructed a comprehensive dataset of 29,978 annotated images following US traffic sign standards. The dataset was carefully curated to include various lighting conditions, distances, and occlusion scenarios to ensure robust model generalization.

  • Training Set: 25,481 images (85%)
  • Validation Set: 4,477 images (15%)
  • Test Set: 20 images (randomly selected for real-time evaluation)

Data sources include raw images collected from city and highway driving in Texas, images from Roboflow, and stop sign images extracted from MS COCO dataset. All images were annotated using LabelImg tool.

Technical Problem Solving

YOLOv7 Architecture Overview

YOLOv7 was selected after comparing multiple real-time object detectors based on speed and accuracy. As a one-stage detector, it provides the optimal balance for real-time autonomous driving applications. The architecture consists of three main components:

  • Backbone: Feature extraction using Conv blocks, MaxPooling, and ELAN (Efficient Layer Aggregation Network)
  • Neck: Feature aggregation using PAFPN structure with SPPCSPC and ELAN-H modules
  • Head: Detection output producing class probabilities, confidence scores, and bounding boxes

Activation Function Optimization: SiLU to ELU

Problem with SiLU

The original SiLU (Sigmoid Linear Unit) activation function in YOLOv7 exhibits outputs approaching zero for negative input values, creating potential for vanishing gradient problems during backpropagation. Similar to ReLU's "dying" problem, when x approaches negative infinity, the output approaches 0. 

SiLU(x) = x × σ(x) = x × (1 / (1 + e^(-x)))
When x → -∞, output → 0 (gradient vanishes)

Solution with ELU

Implemented ELU (Exponential Linear Unit) activation function, which produces negative outputs and pushes mean activations closer to zero. This reduces bias shift and speeds up learning by moving gradients closer to the unit natural gradient. 

ELU(x) = x,              if x > 0
ELU(x) = α(e^x - 1),     if x ≤ 0  (α = 1.0)
Preserves gradient flow for negative inputs

📷 Suggested Image: SiLU vs ELU Activation Function Graphs (Figure 5.4 & 5.5 from thesis)
(Side-by-side comparison showing function curves and their derivatives)

Key Benefits of ELU

  • Negative Outputs: Unlike ReLU/SiLU, ELU produces negative values, allowing the mean to be pushed closer to zero
  • Reduced Bias Shift: Zero-centered activations speed up training convergence
  • Gradient Preservation: Maintains gradient flow through deep networks, crucial for detecting small distant objects
  • Architecture-wide Impact: Modified all CBS (Conv-BatchNorm-SiLU) blocks throughout Backbone, Neck, and Head

ROS Integration & Real-Time Testing

Beyond model training, this project implemented a complete real-time testing pipeline using Robot Operating System (ROS 1 Melodic) on Ubuntu 18.04 LTS:

System Architecture

The testing system uses ROS's publisher-subscriber architecture:

  • Publisher: Camera images from recorded rosbag files (not used for training to prevent overfitting)
  • Subscriber: Python node that loads the trained model weights and performs inference
  • Output: Real-time bounding box visualization with confidence scores and class labels

Testing Methodology

  • Independent Test Data: Rosbag recordings were specifically NOT used for training to ensure unbiased evaluation of real-world performance
  • Speed Variation Testing: Evaluated at multiple speeds (0, 10, 35, 40, 75 mph) to assess performance across driving conditions
  • Environmental Diversity: Tested in city streets, highways, intersections, and varying lighting conditions
  • Camera Configuration: Running at up to 30 Hz depending on brightness and other factors

Limitations & Lessons Learned

Environmental Sensitivity

Under strong direct sunlight conditions, both models occasionally misclassified red traffic lights as yellow. This finding underscores the importance of comprehensive data augmentation strategies including HDR simulation, varied lighting conditions, and color jittering in training pipelines.

Trade-off in Shadow Regions

The ELU activation function modification, while improving overall metrics, showed slight performance degradation in specific shadow regions (e.g., under tree canopies). The original model performed better in these specific conditions, revealing an interesting trade-off for future research.

Yellow Light Performance

Yellow traffic light detection showed only 58.5% mAP, significantly lower than other classes. Root causes identified: (1) Limited dataset size compared to red/green lights, (2) Shape variations (vertical vs horizontal light configurations), (3) Color similarity to some light housings.

Dataset Quality Uncertainty

The uncertainty of how much data is required to achieve optimal performance remains. Resolution variations across the dataset (some blurred, some noisy, some clear) affected training consistency. High-speed driving further degrades camera resolution.

Key Takeaways

  • Activation Function Impact: Selection significantly affects detection performance in edge cases; no single function is optimal for all scenarios
  • Real-world vs Benchmark Gap: Models performing well on test sets may fail in real-world scenarios not represented in training data
  • Data Quality > Quantity: Diverse, high-quality annotations matter more than sheer volume
  • Domain-specific Augmentation: Traffic-specific augmentations (lighting, weather, motion blur) are crucial for robust perception
  • End-to-end Testing: ROS integration for real-time validation is essential before deployment

Conclusion

This research demonstrated that strategic modification of the activation function from SiLU to ELU in YOLOv7 can improve traffic sign and light detection performance, particularly for distant objects and in challenging real-world driving scenarios.

The modified model achieved 93.4% mAP@0.5 compared to 92.3% for the original, with notable improvements in recall (+1.0%) and F1-score (+1.0%). Real-time testing via ROS confirmed superior performance in detecting traffic lights at distances where the original model failed, and resolved misclassification issues between similar-looking traffic signs.

We conclude that the modified model has better performance than the original model for real-time autonomous driving applications.

Future Work

  • Implement adaptive activation functions that can switch between SiLU/ELU based on input characteristics
  • Expand dataset with weather-specific augmentations (rain, fog, snow)
  • Investigate attention mechanisms for improved small object detection
  • Deploy on edge devices (Jetson) for embedded autonomous vehicle applications
