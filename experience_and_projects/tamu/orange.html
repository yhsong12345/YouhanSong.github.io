Orange Harvesting Robot (September 2022 ~ December 2022)

Team Trial & Error - Texas A&M University

Agriculture is one of the most important industries, and harvesting oranges is a labor-intensive task. The average age of farmers is 57.5 years old, and the agricultural population is gradually decreasing due to urbanization. Compared to fruits like strawberries and tomatoes, harvesting oranges is difficult because they grow on tall trees. The cost of production for oranges ranges from $2.22 to $2.83 per pound.

This project develops an autonomous orange harvesting robot to replace manual labor and reduce costs. The system integrates RGB-D sensing with YOLOv7 for orange detection, feedforward + PID control for manipulator control, and a three-finger gripper with scissors for harvesting. The entire system is built on ROS2 Galactic.

Overall System Architecture

The entire system comprises three main parts:

  • Mobile Platform: Husky UGV A200 (Clearpath Robotics) - 75kg max payload, integrated with ROS for navigation
  • Robot Arm: UR5 6-DOF manipulator with LIFTKIT-UR motorized lift stage (0.5m ~ 1.4m height range)
  • End Effector: Custom three-finger gripper with scissors, Intel RealSense D435i, and force sensors

Hardware Components

Mobile Platform

  • Husky UGV A200: Outdoor autonomous mobile base
  • Hokuyo URG-04LX LiDAR: Obstacle detection and mapping
  • GNSS Antenna Pack: Global positioning
  • 3DM-GX5-IMU: Acceleration and orientation sensing
  • Raspberry Pi 4 (8GB): ROS2 Galactic system
  • NVIDIA Jetson Nano: Image classification and object detection

Manipulator

  • Universal Robots UR5: 6-DOF robot arm (5kg capacity, 850mm reach)
  • LIFTKIT-UR-900-1100: Motorized lift stage for height adjustment

End Effector

  • Intel RealSense D435i: RGB-D camera with IMU
  • FUTEK LSB200 Load Cells (x3): Force sensing for gentle grasping
  • VL6180X Proximity Sensor: Distance measurement between gripper and orange
  • Nema 11 Stepper Motor: Finger actuation via worm gear
  • MG995R Servo Motor: Scissor blade rotation

Control System Strategy

The system operates in three sequential control strategies:

Strategy 1: Autonomous Navigation

  • ROS Navigation 2 Stack with SLAM Toolbox for path planning
  • Extended Kalman Filter for sensor fusion (odometry, GPS, IMU)
  • Dynamic Window Approach (DWA) for obstacle avoidance
  • PID controller for trajectory following

Strategy 2: Manipulator Control

  • Lift stage adjusts height until orange is within reach
  • Inverse kinematics (Newton-Raphson numerical method) generates trajectory
  • Feedforward + PID feedback controller for precise motion

Strategy 3: End Effector Control

  • Hybrid force and position control system
  • Position control for gripper open/close
  • Force control to prevent orange damage
  • Servo rotates scissor blade to cut stem

Robot Arm Kinematics & Dynamics

Forward Kinematics (DH Convention)

The transformation from frame i-1 to i using Denavit-Hartenberg parameters:

Ti-1,i = Rotz(θi) Transz(di) Transx(ai) Rotx(αi)

Inverse Kinematics (Newton-Raphson Method)

  1. Pick initial guess θ⃗₀ and desired transformation T0,d
  2. Get V⃗b from [V⃗b] = ln(T0,b-1(θ⃗i)T0,d)
  3. While ‖w⃗b‖ > εw or ‖v⃗b‖ > εv: θ⃗i+1 = θ⃗i + Jb-1(θ⃗i)V⃗b

Orange Detection (YOLOv7)

The robot uses an Intel RealSense D435i RGB-D camera for object detection. YOLOv7 was chosen for its real-time performance and high accuracy compared to two-stage detectors like R-CNN.

  • Algorithm: YOLOv7 (one-stage object detection)
  • Training: Custom orange dataset with open-source code
  • Output: Bounding boxes with confidence scores
  • Depth: Intel RealSense SDK 2.0 provides distance to detected oranges

End Effector Design

A novel three-finger gripper with integrated cutting mechanism:

  • Gripper Mechanism: Worm gear driven by stepper motor for precise finger control
  • Cutting Mechanism: Two scissor blades (one fixed, one servo-actuated)
  • Sensing: Load cells on finger tips for force feedback, proximity sensor at center
  • Materials: Aluminum fingers and bracket, stainless steel scissors

Hybrid Force/Position Control

The end effector uses a hybrid control system that switches between position control (for opening/closing) and force control (to prevent orange damage). A DAQ system collects force data from load cells, and a threshold-based switch mode determines which control strategy to apply.
