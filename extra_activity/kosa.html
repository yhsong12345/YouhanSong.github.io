1. Development of Autonomous Mobile Robot with NVIDIA Jetson

Certification: KOSA-2025-115-1-06호(click)

Objective

  • Understand hardware and software of NVIDIA Jetson
  • Learn Robot Programming based on ROS
  • Understand and Learn skill to develop AMR (Autonomous Mobile Robot) with computer vision or other deep learning model
  • Design and Implement the actual prototype of AMR

In this lecture, we learned how to use ROS. We created and built packages to run the autonomous mobile robot, including LiDAR, camera, GPS, and IMU for sensing, as well as path planning and localization. After building the packages, we ran the AMR in real-time in the real world.

2. Multi-Modal Prompt for LLM

Certification: KOSA-2025-108-1-11호(click)

Objective: Learn and understand how to generate proper responses based on inputs of mixed text, images, or other types of various inputs. This improves the interaction with LLMs to output more appropriate, comprehensive, and exclusive responses for many cases.

In this lecture, we learned how to search for information using LLMs such as ChatGPT, Gemini, etc. To get proper responses, sophisticated prompts were written. Additionally, we learned how to build RAG (Retrieval-Augmented Generation) to search and retrieve desired answers from information stored as vectors.
