# Presentation Guide

## How to Use

1. **Open the Presentation**
   - Open `presentation.html` in a web browser
   - All 14 slides will be loaded automatically

2. **Navigation**
   - Use the navigation buttons at the bottom to move between slides
   - Keyboard shortcuts:
     - `Arrow Right` or `Space`: Next slide
     - `Arrow Left`: Previous slide
     - `F`: Toggle fullscreen

3. **PDF Export**
   - Click the PDF Export panel in the top-right corner
   - Select which slides you want to export (checkboxes)
   - Click "Select All" or "Deselect All" for quick selection
   - Choose:
     - **Export Selected to PDF**: Export only checked slides
     - **Export All Slides**: Export all 14 slides
   - The browser's print dialog will open - select "Save as PDF"
   - **Important**: Enable "Background graphics" in print settings

## Features

- ✅ All slides combined in one presentation
- ✅ Project names aligned to left-top (fixed)
- ✅ Performance accuracy gauges visible and functional
- ✅ Slide selection for PDF export
- ✅ Print-optimized styles for PDF export
- ✅ Fullscreen mode support
- ✅ Keyboard navigation

## Notes

- Make sure all slide files (slide01.html through slide14.html) are in the same directory as presentation.html
- Charts and gauges will automatically initialize when slides are viewed
- For best PDF export results, use Chrome or Edge browser

## Troubleshooting

**Charts not showing?**
- Wait a moment for the slide to fully load
- Refresh the page if charts don't appear

**PDF export issues?**
- Make sure "Background graphics" is enabled in print settings
- Use Chrome or Edge for best results
- Ensure all slide files are in the same directory
