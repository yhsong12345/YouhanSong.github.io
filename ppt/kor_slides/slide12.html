Project 08 Robotics Engineering

Robotic Arm Object Relocator

3D Printed Robotic Arm & Automated Conveyor System

2022.09 - 2022.12

Project Goal

3D Printing 기반 로봇 팔 설계/제작 및 Inverse Kinematics 기반 센서 융합 자동 제어 시스템 구현. 컨베이어 벨트 간 물체 자동 이송 자동화 달성.

Key Responsibilities

  • Inverse Kinematics 계산 및 제어 알고리즘 구현
  • 센서 통합 및 자동화 시스템 개발
  • Arduino 기반 임베디드 시스템 통합

Key Achievements

  • Servo 모터와 Gripper의 정확한 위치 제어를 위해 기구학(Kinematics) 계산을 수행하고 이를 C언어 코드로 구현하여 정밀 제어 달성
  • 거리 센서를 활용하여 물체가 감지 범위 내로 들어오면 자동으로 집어서 이송하고 복귀하는 자동화 루틴(Automation Routine) 구현
  • Arduino 보드에 제어 알고리즘을 탑재하여 센서 데이터 처리와 모터 제어를 실시간으로 연동하는 임베디드 시스템 통합 성공

Tech Stack

Arduino C/C++ Solidworks 3D Printing

Hardware Implementation
