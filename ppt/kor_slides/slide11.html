Project 07 Autonomous Driving Perception

Autonomous Vehicle for All Project (Texas A&M)

Traffic Sign & Signal Detection for Autonomous Vehicle

Texas D.O.T (텍사스 교통국)

2022.05 - 2023.08

Project Goal

Texas D.O.T 연구 과제로 미국 도시 외곽 환경(Rural Area)에서의 자율주행 시스템 개발. 교통 표지판/신호등 인지 모듈 개발 및 ROS 기반 실차 통합까지 End-to-End 연구 수행.

Key Responsibilities

  • Multi-sensor(Camera, LiDAR) 데이터 수집 및 라벨링
  • Traffic Sign/Signal Detection 모델 개발
  • ROS 환경 통합 및 실시간 추론 파이프라인 구축
  • 실제 자율주행 차량 탑재 및 실증 테스트

Key Achievements

  • Texas 현지 도로 환경에 맞는 자체 데이터셋 구축 및 라벨링
  • 다양한 조도, 날씨, 가려짐 조건에서 강인한 교통 표지판 및 신호등 탐지 모델 개발
  • ROS 환경 통합 및 자율주행 차량 제어 시스템과의 실시간 연동 파이프라인 구축
  • 데이터 수집 (Point Cloud, Image, Video 등)부터 모델 설계, 학습, 차량 탑재 및 테스트까지 전 과정 주도 수행

Tech Stack & Environment

Python PyTorch OpenCV ROS Ubuntu 20.04 Autoware Cloud Compare
