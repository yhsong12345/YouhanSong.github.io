활성화 함수 비교

SiLU (Original) Sigmoid Linear Unit

f(x) = x · σ(x)

σ(x) = 1 / (1 + e-x)

ReLU의 Dying 문제 완화

x → -∞ 시 output → 0

Vanishing Gradient 발생 가능

ELU (Modified) Exponential Linear

f(x) = x, if x > 0

f(x) = α(ex - 1), if x ≤ 0

음수 출력 → Mean ≈ 0

Bias 감소 → 학습 가속
