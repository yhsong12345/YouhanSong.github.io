Project 01 Natural Language Processing

한국어 특화 LLM 개발

Korean Specific Large Language Model Research & Development

사내 R&D

2025.06 - 2025.10

Project Goal

오픈소스 베이스 모델(Llama, Qwen)을 기반으로 한국어 데이터 처리에 특화된 전처리 파이프라인 구축 및 Instruction Tuning을 수행하여 한국어 추론 능력을 극대화한 LLM 개발

Key Responsibilities

  • 데이터 전처리 파이프라인 설계 및 구현 (NeMo Curator 기반)
  • 한국어 특화 Tokenizer 연구 및 최적화
  • LLM Fine-tuning (CPT, SFT, DPO, PPO) 실험 및 성능 개선
  • 벤치마크 평가 및 성능 분석 리포트 작성

Tech Stack

Python Bash PyTorch NeMo Curator HuggingFace

Environment

H100 Cluster A100 Cluster Ubuntu 22.04 Team: 5명

Data & Training Pipeline

Data Pre-processing

NeMo Curator

  • Clean Architecture 적용
  • 데이터 정제 파이프라인 구축
  • 한국어 Corpus(말뭉치) 필터링
Model Training

Fine-tuning

  • Continued Pre-training (CPT)
  • Supervised Fine-tuning (SFT)
  • DPO / PPO Reinforcement
  • 한국어 Tokenizer 확장
Evaluation

Benchmarks

  • GSM8K (Reasoning)
  • IFEval_Ko (Instruction)
  • 성능 지표 리포팅

Key Achievements & Tasks

Advanced Data Pipeline

Nvidia NeMo Curator를 활용하여 대규모 데이터셋 처리를 위한 Clean Architecture 기반의 모듈형 파이프라인을 구축, 데이터 전처리 효율성 증대

Tokenizer Optimization

Llama/Qwen 등 영미권 모델의 한국어 처리 효율 저하 문제를 해결하기 위해 한국어 특화 Tokenizer 연구 및 적용, 토큰 효율성 개선

Training Methodologies

SFT, DPO, PPO 등 최신 학습 방법론을 적용하여 모델의 지시 이행 능력(Instruction Following) 및 한국어 답변 품질 향상

Quantitative Evaluation

gsm8k, ifeval_ko 등 객관적인 벤치마크 데이터셋을 활용하여 모델 성능을 정량적으로 평가하고 개선 방향 도출
