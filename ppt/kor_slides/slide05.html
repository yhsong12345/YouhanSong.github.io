Project 01 Natural Language Processing

한국어 특화 LLM 개발

Korean Specific Large Language Model Research & Development

2025.06 - 2025.10

주요내용

한국어 환경에서 높은 성능과 응답 품질을 보이는 거대 언어 모델을 연구하고 개발하는 사내 R&D 프로젝트입니다. 데이터 전처리부터 모델의 다양한 훈련 기법 적용 및 성능 평가까지 전반적인 LLM 개발주기를 다루었습니다.

담당업무

  • NeMo Curator 기반 데이터 전처리 파이프라인 구축
  • LLM 연구 (훈련 레시피 및 토크나이저 확장)

Technical Challenges & Solutions

Data & Tokenizer 151K→165K

C: 한국어 데이터 부족 + 토큰 효율성 저하 S: Tokenizer 확장 + Weight Averaging 초기화

Training Strategy 4-Stage

C: 한국어↔영어/수학 Trade-off S: CPT→SFT→DPO→GRPO 순차 학습

Performance Balance SLERP

C: CPT 후 수학 성능 하락 S: Base+CPT SLERP merge (t=0.6)

Tech Stack

Python PyTorch NeMo H100/A100
