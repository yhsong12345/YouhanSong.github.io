Project Overview

An intelligent CCTV control system enhancement project for the Vietnam National Police. Real-time detection of vehicles and pedestrians on roads, license plate recognition (LPR), and attribute analysis (vehicle type, brand, color, etc.) to maximize security and traffic control efficiency.

Key Responsibilities

  • Data collection guideline creation and labeling process establishment
  • Detection and Recognition model architecture modification and training optimization
  • Model performance maximization through hyper-parameter tuning

Tech Stack & Env
