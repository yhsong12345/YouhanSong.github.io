Tanzania Smart Gate

Customs Cargo & Driver Authentication System

Tanzania Customs Authority CUPIA

2024.01 - 2024.12

Project Overview

A smart gate system to automate customs clearance procedures for the Tanzania Customs Authority. Automatically recognizes container numbers and vehicle license plates, and verifies driver identity through face recognition to simultaneously enhance customs security and efficiency.

Key Responsibilities

  • License plate and container number area detection model development
  • License plate and container number recognition model development
  • Model lightweighting and inference optimization using ONNX, OpenVINO

Tech Stack & Env

Python PyTorch ONNX/OpenVINO Ubuntu 20.04 A100 GPU
